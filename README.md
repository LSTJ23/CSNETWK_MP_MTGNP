## Known Limitations & Deviations from RFC

* Based on the specifications, the decks are limited to 1–50 cards in validation checks, whereas the official Magic the Gathering game formats typically require a 60-card minimum.
* Each card’s effects were simplified into direct blocker-to-attacker mappings rather than a fully layered MTG comprehensive rules engine.
* The priority feature follows a basic and simplified 2-pass sequence to resolve stack items or transition phases.
* The server strictly enforces a maximum of two (2) concurrent client sockets in the lobby state, and does not support multi-table matches or spectator sockets.
* The server enforces a hard 60-second priority timer per turn without dynamic pause, resume, or extension protocols.
